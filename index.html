Introduction to SQL

SQL stands for Structured Query Language. It helps people retrieve, filter, sort, and combine information stored in relational databases. Businesses use SQL to analyze sales, manage customers, and make data-informed decisions.

1. SELECT — Retrieve Data

SELECT chooses which columns to display from a table.

SELECT name, email
FROM customers;

Explanation: This query returns the name and email columns for every row in the customers table.

2. WHERE — Filter Data

WHERE limits results to rows that match a condition.

SELECT name, email
FROM customers
WHERE city = 'Denver';

Explanation: This query returns only customers whose city value is Denver.

3. ORDER BY — Sort Data

ORDER BY sorts results. DESC means descending, while ASC means ascending.

SELECT name, total_spent
FROM customers
ORDER BY total_spent DESC;

Explanation: This query lists customers from the highest total_spent value to the lowest.

4. JOIN — Combine Tables

JOIN combines related information from two tables using a shared key.

SELECT orders.order_id, customers.name
FROM orders
JOIN customers
  ON orders.customer_id = customers.customer_id;

Explanation: This query pairs each matching order with the name of the customer who placed it.

Why SQL Matters

SQL can help answer practical questions, such as which customers live in a particular city, which customers spend the most, and which orders belong to each customer.

Key takeaway: SELECT retrieves data, WHERE filters it, ORDER BY sorts it, and JOIN connects related tables.
