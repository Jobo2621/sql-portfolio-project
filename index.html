Introduction

SQL is used to find and organize information in databases. This project shows basic and advanced SQL queries that can help businesses understand customers and sales.

The examples use customers and orders tables. They are examples and have not been tested on a real database.

SQL Basics

1. SELECT

SELECT name, email
FROM customers;

Shows customer names and emails.

2. WHERE

SELECT name, email
FROM customers
WHERE city = 'Denver';

Shows customers who live in Denver.

3. ORDER BY

SELECT name, total_spent
FROM customers
ORDER BY total_spent DESC;

Lists customers from highest spending to lowest.

4. JOIN

SELECT orders.order_id, customers.name
FROM orders
JOIN customers
ON orders.customer_id = customers.customer_id;

Connects orders to the customers who made them.

Advanced SQL

1. Top Five Customers

SELECT customer_id, SUM(total_amount) AS spent
FROM orders
GROUP BY customer_id
ORDER BY spent DESC
LIMIT 5;

SUM adds up each customer's orders. This query shows the five customers who spent the most.

2. Monthly Sales

WITH sales AS (
  SELECT DATE_TRUNC('month', order_date) AS month,
         SUM(total_amount) AS total
  FROM orders
  GROUP BY DATE_TRUNC('month', order_date)
)
SELECT month, total,
       LAG(total) OVER (ORDER BY month) AS prev
FROM sales
ORDER BY month;

This adds up sales each month and shows the previous month's sales beside it. It uses PostgreSQL syntax.

3. Spending Above Average

SELECT customer_id, SUM(total_amount) AS spent
FROM orders
GROUP BY customer_id
HAVING SUM(total_amount) > (
  SELECT AVG(total_amount) FROM orders
)
ORDER BY spent DESC;

This finds customers whose total spending is above the average order amount. The average here is per order, not per customer.

Conclusion

SQL can help businesses organize information, track sales, compare results and identify important customers. These queries show how basic and advanced SQL can answer business questions.
