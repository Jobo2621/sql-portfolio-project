Introduction to SQL

SQL stands for Structured Query Language. It is used to retrieve, organize, and analyze information in relational databases. Businesses use SQL to understand customer behavior, track sales, and support data-informed decisions.

Project objective: Demonstrate basic SQL commands and more advanced techniques for analyzing customer and sales data.

Example data model: The queries assume an orders table containing customer_id, order_id, order_date, and total_amount. These are illustrative examples and have not been run against a real database.

SQL Fundamentals

SELECT — Retrieve Data

SELECT name, email
FROM customers;

This returns the name and email columns for every customer.

WHERE — Filter Data

SELECT name, email
FROM customers
WHERE city = 'Denver';

This returns only customers whose city is Denver.

ORDER BY — Sort Data

SELECT name, total_spent
FROM customers
ORDER BY total_spent DESC;

This sorts customers from the highest spending value to the lowest.

JOIN — Combine Tables

SELECT orders.order_id, customers.name
FROM orders
JOIN customers
  ON orders.customer_id = customers.customer_id;

This matches each order to the corresponding customer name.

Advanced SQL Analysis

These three examples use grouping, subqueries, and window functions to answer realistic business questions.

Query 1: Who are the top five customers by spending?

GROUP BY · SUM · ORDER BY · LIMIT 
SELECT
    customer_id,
    SUM(total_amount) AS total_spent
FROM orders
GROUP BY customer_id
ORDER BY total_spent DESC
LIMIT 5;
How it works:
  • SUM(total_amount) adds up each customer's order amounts.
  • GROUP BY customer_id creates one result per customer.
  • ORDER BY ... DESC ranks the largest totals first.
  • LIMIT 5 returns only the top five customers.
Business value: Helps identify high-value customers for loyalty programs and customer-retention efforts.

Query 2: How do sales change month to month?

Subquery · SUM · LAG · Window Function 
WITH monthly_sales AS (
    SELECT
        DATE_TRUNC('month', order_date) AS sales_month,
        SUM(total_amount) AS revenue
    FROM orders
    GROUP BY DATE_TRUNC('month', order_date)
),
sales_comparison AS (
    SELECT
        sales_month,
        revenue,
        LAG(revenue) OVER (
            ORDER BY sales_month
        ) AS previous_month_revenue
    FROM monthly_sales
)
SELECT
    sales_month,
    revenue,
    previous_month_revenue,
    revenue - previous_month_revenue AS sales_change
FROM sales_comparison
ORDER BY sales_month;
How it works:
  • The first CTE, monthly_sales, groups orders into months and calculates each month's revenue.
  • LAG() looks at the previous month's revenue without joining the table to itself.
  • The final query subtracts the previous month's revenue from the current month's revenue.
Business value: Helps businesses spot periods of growth or declining revenue.
SQL dialect: PostgreSQL, using DATE_TRUNC and LAG.

Query 3: Which customers spend above the average?

Subquery · GROUP BY · HAVING · AVG 
WITH customer_spending AS (
    SELECT
        customer_id,
        SUM(total_amount) AS total_spent
    FROM orders
    GROUP BY customer_id
)
SELECT
    customer_id,
    total_spent
FROM customer_spending
WHERE total_spent > (
    SELECT AVG(total_spent)
    FROM customer_spending
)
ORDER BY total_spent DESC;
How it works:
  • The CTE calculates the total spending for each customer.
  • The subquery calculates the average of those customer totals.
  • The outer query returns customers whose total exceeds that average.
Business value: Helps identify above-average customers for targeted marketing and retention.

Conclusion

This project demonstrates how SQL can move beyond retrieving individual records to answer larger business questions.

  • Aggregation summarizes sales and customer activity.
  • Common table expressions organize complex queries into readable steps.
  • Window functions compare values across time periods.
  • Subqueries compare individual customer totals against an overall average.

These techniques can support customer analysis, sales reporting, and business decision-making.
